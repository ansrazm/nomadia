Data wilayah administratif Indonesia (provinsi, kabupaten/kota, kecamatan) untuk dropdown alamat checkout.

Sumber : idn-area-data v4.0.1 (https://github.com/fityannugroho/idn-area-data), berasal dari sumber resmi Kemendagri.
Lisensi: Open Database License (ODbL) 1.0 untuk datanya (https://opendatacommons.org/licenses/odbl/1-0/).
         Berkas JSON di folder ini adalah turunan dari database itu dan ikut berlisensi ODbL; kode aplikasi lainnya tidak terkena.
Ubah  : dikelompokkan per provinsi, nama provinsi disamakan dengan lib/regions.ts, diurutkan abjad.
Buat ulang: lihat web/scripts/gen-wilayah.mjs.
